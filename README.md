One line: the funniest single-line resignation letter — the last day is Friday, unless the printer jams again.

> My last day is Friday, unless the printer jams again, in which case it was yesterday.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```

`main.py` uses only the Python 3.13 standard library and writes the entry to `/output/entry.txt`.
